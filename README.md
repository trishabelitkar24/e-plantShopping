# e-plantShopping – Paradise Nursery

Paradise Nursery is a responsive online houseplant shopping application built with React, Redux Toolkit, React Router, and CSS.

## Features
- Landing page with a "Get Started" button
- Home, Plants, and Cart navigation
- Three plant categories with six unique plants in each category
- Plant cards with image, name, description, price, and Add to Cart button
- Redux-powered shopping cart
- Add, remove, and update item quantities
- Add to Cart button becomes disabled after an item is added
- Cart badge showing the total number of items
- Per-product subtotal and overall cart total
- Continue Shopping and Checkout buttons
- Responsive layout for desktop, tablet, and mobile

## Technologies
- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- HTML5 and CSS3

## Run locally
1. Install Node.js (LTS).
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Production build
Run `npm run build`. The deployable website is generated in the `dist` folder.

## GitHub Pages deployment
For GitHub Pages, configure the Vite `base` option in `vite.config.js` to `'/e-plantShopping/'` if deploying as a project site, then build and publish the `dist` folder. Alternatively, deploy the project with Netlify or Vercel.
